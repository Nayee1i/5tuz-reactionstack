# SkillFlow — Система мониторинга развития технических навыков

**SkillFlow** — это современное веб-приложение для управления производительностью сотрудников (Performance Review System). Платформа позволяет отслеживать прогресс развития технических навыков, планировать и проводить встречи 1:1, администрировать организационную структуру и управлять индивидуальными планами развития.

---

## 🚀 Ключевые возможности

- **Управление оргструктурой**: иерархия подразделений, направления разработки (BACK, FRONT, QA), назначение руководителей.
- **Справочник навыков**: централизованный каталог технических скиллов с привязкой к направлениям.
- **Планы развития**: индивидуальные планы обучения сотрудников с отслеживанием прогресса и статусов (в работе, подтверждён, есть отставание).
- **Управление встречами**: планирование встреч различных типов (1:1, Skill Review, Problem Review, Retrospective), фиксация итогов и привязка результатов к конкретным навыкам.
- **Профиль сотрудника**: дашборд с достижениями, прогресс-барами навыков, биографией и возможностью загрузки аватара.
- **Административная панель**: полное управление пользователями, их ролями и распределением по подразделениям.
- **Безопасность**: JWT-аутентификация, хеширование паролей (bcrypt), защита маршрутов.

## ⚡ Быстрый старт (Docker)

Рекомендуемый способ запуска проекта для разработки и тестирования.

1. **Склонируйте репозиторий** (если еще не сделано):
   ```bash
   git clone <url-репозитория>
   cd <имя-папки-проекта>
   ```

2. **Настройте переменные окружения**:
   ```bash
   cp .env.example .env
   ```
   *Откройте файл `.env` и замените значения-заглушки на актуальные (особенно `DATABASE_URL`, `JWT_SECRET` и пароли).*

3. **Запустите контейнеры**:
   ```bash
   docker-compose up -d --build
   ```

4. **Инициализируйте базу данных** (выполните в контейнере бэкенда):
   ```bash
   docker-compose exec backend npx prisma db push
   docker-compose exec backend npm run seed # Если требуется заполнить БД тестовыми данными
   ```

5. **Доступ к приложению**:
   - **Основное приложение (через Nginx)**: http://localhost
   - **Frontend (напрямую)**: http://localhost:3000
   - **Backend API**: http://localhost:3001/api
   - **Health Check**: http://localhost:3001/api/health

## 💻 Локальная разработка (без Docker)

Если вы предпочитаете запускать сервисы напрямую на хост-машине.

### Предварительные требования
- Node.js >= 18
- PostgreSQL (запущен и доступен)
- Redis (запущен на порту 6379)

### Backend
```bash
cd backend
npm install
npx prisma generate
npx prisma db push
npm run dev
```
*Сервер запустится на порту `3001`.*

### Frontend
```bash
cd frontend
npm install
npm start
```
*Приложение запустится на порту `3000` (или `5173`, в зависимости от конфигурации скрипта).*

> **Примечание**: Для локальной разработки без бэкенда установите `REACT_APP_USE_MOCK=true` в файле `frontend/.env`, чтобы использовать встроенные моки данных.

## ⚙️ Переменные окружения (.env)

| Переменная | Описание | Пример |
|------------|----------|--------|
| `PORT` | Порт сервера Backend | `3001` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://user:pass@localhost:5432/db?schema=public` |
| `REDIS_URL` | Строка подключения к Redis | `redis://localhost:6379` |
| `JWT_SECRET` | Секретный ключ для подписи токенов | `your-super-secret-key-here` |
| `REACT_APP_API_URL` | Базовый URL для API-запросов с фронтенда | `http://localhost:3001/api` |
| `REACT_APP_USE_MOCK` | Включить режим моков на фронтенде (`true`/`false`) | `false` |

## 📡 Основные API эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/api/auth/login` | Аутентификация пользователя, выдача JWT |
| `POST` | `/api/auth/logout` | Завершение сессии |
| `GET`  | `/api/users/me/profile` | Получение полного профиля текущего пользователя |
| `POST` | `/api/users/me/avatar` | Загрузка аватара пользователя (multipart/form-data) |
| `GET`  | `/api/meetings/upcoming` | Список предстоящих встреч |
| `POST` | `/api/meetings` | Создание новой встречи |
| `GET`  | `/api/directions` | Получение списка направлений (BACK, FRONT, QA) |

*Полная документация API доступна через исходный код в папке `backend/src/routes/`.*
