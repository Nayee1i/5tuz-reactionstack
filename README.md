# 5tuz-reactionstack

## Быстрый старт
1. `cp .env.example .env`
2. `docker-compose up -d`
3. Frontend: http://localhost:3000
4. Backend API: http://localhost:3001/api

## Локальная разработка (без Docker)
### Backend
cd backend
npm install
npm run dev

### Frontend  
cd frontend
npm install
npm start
